
# 🃏 Blackjack Game — Python

A simple console-based Blackjack game built using Python.

## 📌 About the Project

This project is a command-line Blackjack game where the player competes against the computer.

The game includes:

* Random card dealing
* Blackjack detection
* Score calculation
* Automatic Ace handling
* Player hit/pass decisions
* Computer gameplay logic
* Win, lose, and draw conditions

## 🛠️ Concepts Used

* Python functions
* `while` and `for` loops
* Lists
* Conditional statements
* `random` module
* User input
* Functions with parameters and return values

## ▶️ How to Run

Make sure Python is installed on your system.

```bash
python blackjack.py
```

Then follow the instructions displayed in the terminal.

## 🎮 Game Rules

* The goal is to get a score as close to 21 as possible without going over.
* An Ace can count as `11` or `1`.
* A Blackjack is a score of `21` with exactly two cards.
* The computer draws cards until its score reaches at least 17.
